# 台灣藥局電商合規設計參考

以下是網站原型採用的保守呈現原則及主管機關來源，供正式營運前與實際藥局業者、藥師及法遵人員核對。此文件不是法律意見。

- 食品藥物管理署於 2024-03-11 說明網路平台違規販售藥品管理，提醒民眾藥品並非一般商品，勿透過網路平台購買來路不明藥品；同時指出非藥商於網路販售藥品可能涉及藥事法規。網站因此預設不把藥品當成一般可直接加入購物車／結帳的商品，並導向門市或藥師諮詢。來源：[食藥署說明網路平台違規販售藥品之管理作為](https://www.fda.gov.tw/tc/newsContent.aspx?cid=4&id=t622653)。
- 食品藥物管理署「醫材商（藥局）通訊交易通路販售醫療器材資訊專區」說明，通訊交易販售資格限依法核准登記的醫療器材商或核准登記的藥局；可販售品項受公告限制；網站需提供品名、許可證或登錄字號、許可證持有人／登錄者及製造業者資訊、業者名稱地址執照字號及諮詢電話，並標示「消費者使用前應詳閱醫療器材說明書」。原型對未核實品項採諮詢模式，不開放下單。來源：[食藥署醫材通訊交易資訊專區](https://www.fda.gov.tw/tc/siteContent.aspx?sid=11680)。
- 食品藥物管理署資料指出，食品廣告不可不實、誇大、易生誤解或宣稱醫療效能；健康食品也只能按核准的保健功效範圍宣稱。原型中的食品文字採一般營養資訊，不宣稱療效。來源：[食藥署食品廣告不得宣稱誇大不實、易生誤解或醫療效能](https://www.fda.gov.tw/TC/csmnewsContent.aspx?id=t623612&mid=267)。

正式上線前，仍須由經營者確認實際藥局與藥商資格、門市資料、商品標示與許可資訊、配送／退換貨條件、發票及個資告知內容，並依最新公告及個別商品分類更新網站。
